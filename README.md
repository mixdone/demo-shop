# Demo Shop Platform

Продуктовая микро-платформа интернет-магазина, разрабатывается в целях тренироки и демонстрации навыков.

## Архитектура и Стек технологий

*   **Frontend / Reverse Proxy:** Nginx (Alpine) — единая точка входа. Оптимизирован для мгновенной отдачи статики с диска, динамические запросы проксирует в бэкенд по протоколу FastCGI.
*   **Backend Application:** PHP-FPM 8.2 (Alpine) — изолированный вычислительный слой, обрабатывающий бизнес-логику магазина.
*   **Database Layer:** MySQL 8.0 — реляционная СУБД для хранения каталога товаров и заказов. Данные изолированы и защищены с помощью Docker Volumes.
*   **Object Storage (S3):** MinIO — локальное S3-совместимое хранилище для медиа-файлов (картинок товаров).

## Структура проекта

```text
.
├── compose.yml         # Главный оркестратор локальной инфраструктуры
├── Dockerfile          # Инструкция сборки оптимизированного PHP-образа
├── nginx.conf          # Конфигурация маршрутизации reverse-proxy (site.conf)
├── .env.example        # Шаблон безопасных переменных окружения
├── init/               # Автоматические SQL-миграции для СУБД
│   └── init.sql
├── shop-assets/        # Стартовые картинки товаров для авто-синхронизации с S3
│   ├── apple.jpg
│   └── orange.jpg
└── site/               # Исходный код веб-приложения (PHP/HTML)
    └── index.php       # Витрина магазина
```

## Инструкция по локальному запуску (Быстрый старт)

Проект полностью автономен и запускается на локальной машине без необходимости платить за облачную инфраструктуру.

### 1. Подготовка окружения
Склонируйте репозиторий, создайте файл `.env` из шаблона и задайте свои секреты:
```bash
cp .env.example .env
```

### 2. Запуск инфраструктуры
Запустите весь стек контейнеров в фоновом режиме. Компоненты поднимутся в строгой и безопасной последовательности:
```bash
docker compose up -d 
```

### 3. Проверка работы
*   **Витрина магазина:** Откройте в браузере [http://localhost](http://localhost) (данные подтянутся из MySQL, картинки — из MinIO).
*   **Консоль MinIO S3:** Доступна по адресу [http://localhost:9001](http://localhost:9001) (вход по ROOT-ключам из вашего `.env`).

### 4. Остановка и очистка томов
```bash
docker compose down -v
```
