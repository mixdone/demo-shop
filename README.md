# Demo Shop Platform

Продуктовая микро-платформа интернет-магазина, разрабатывается в целях тренироки и демонстрации навыков.

## Архитектура и Стек технологий

*   **Frontend / Reverse Proxy:** Nginx (Alpine) — единая точка входа. Оптимизирован для мгновенной отдачи статики с диска, динамические запросы проксирует в бэкенд по протоколу FastCGI.
*   **Backend Application:** PHP-FPM 8.2 (Alpine) — изолированный вычислительный слой, обрабатывающий бизнес-логику магазина.
*   **Database Layer:** MySQL 8.0 — реляционная СУБД для хранения каталога товаров и заказов. Данные изолированы и защищены с помощью Docker Volumes.
*   **Object Storage (S3):** MinIO — локальное S3-совместимое хранилище для медиа-файлов (картинок товаров).

## Реализованные юзкейсы

###  Юзкейс «Витрина и Проксирование S3»
*   **User Story:** Я, как покупатель, хочу зайти на главную страницу, чтобы увидеть актуальный список товаров с ценами и изображениями.

### Юзкейс «Регистрация нового аккаунта»
*   **User Story:** Я, как гость, хочу создать профиль на сайте, чтобы получить возможность совершать покупки.

### Юзкейс «Авторизация пользователей и Корзина»
*   **User Story:** Я, как зарегистрированный покупатель, хочу войти в систему под своим логином, чтобы сайт меня узнавал и сохранял историю моих покупок.

### Юзкейс «Управление каталогом (Админка)»
*   **User Story:** Я, как контент-менеджер, хочу загружать новые товары, указывать цены и прикреплять изображения через веб-интерфейс.

## Инструкция по локальному запуску (Быстрый старт)

Проект полностью автономен и запускается локально.

### 1. Запуск
```bash
cp .env.example .env

# задайте свои секреты в .env

docker compose up -d 

```

### 2. Проверка работы
*   **Витрина магазина:** Откройте в браузере [http://localhost](http://localhost) (данные подтянутся из MySQL, картинки — из SeaweedFS).
*   **S3-совместимый endpoint SeaweedFS:** [http://localhost:8333](http://localhost:8333) (используется приложением через AWS SDK).
*   **Filer SeaweedFS:** [http://localhost:8888](http://localhost:8888) (веб-интерфейс для просмотра файлов).

### 3. Остановка и очистка томов
```bash
docker compose down -v
```
